# Telegram-бот с мини-играми

Telegram-бот на Python с несколькими играми и статистикой игроков.

## Возможности

- «Угадай число» с уровнями сложности: лёгкий (1–10), средний (1–100) и сложный (1–1000).
- «Камень, ножницы, бумага».
- Подбрасывание монеты и бросок кубика.
- Таблица лидеров по очкам: победа даёт 3 очка, ничья — 1, поражение — 0.
- Случайные факты и статистика игр.

## Требования

- Python 3.10 или новее.
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather).

## Установка и запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Создайте файл `.env` рядом с `playground.py` и добавьте токен:

   ```dotenv
   BOT_TOKEN=ваш_токен_бота
   ```

4. Запустите бота:

   ```powershell
   python playground.py
   ```

Данные игроков — победы, поражения, ничьи, очки, сыгранные игры, броски монеты и кубика — сохраняются в `players.json` через `save_data()` и загружаются при запуске через `load_data()`. Если файл ещё не создан, бот попробует перенести старые данные из `bot_data.json`, а если их нет — начнёт с пустой статистики. Файлы с данными исключены из Git.

Чтобы запустить бота в отладчике VS Code, выберите конфигурацию **Python: Playground bot (pause on save)** и нажмите **F5**. После `/stats` или `/coin` выполнение остановится перед записью JSON; словарь для сохранения будет виден в **Variables → Locals → data**. Нажмите **F5** ещё раз, чтобы продолжить.

## Команды

- `/start` и `/help` — справка.
- `/guess` — выбрать уровень игры «Угадай число».
- `/guess easy`, `/guess medium`, `/guess hard` — начать игру с выбранной сложностью.
- `/rps` — сыграть в «Камень, ножницы, бумага».
- `/coin` — подбросить монету.
- `/dice` — бросить кубик; например, `/dice 20`.
- `/fact` — получить случайный факт.
- `/stats` — посмотреть статистику.
- `/leaderboard` — посмотреть топ-5 игроков по очкам.
- `/fame` — посмотреть зал славы игроков с 3 и более победами.
