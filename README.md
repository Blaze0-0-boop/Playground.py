# Telegram-бот с мини-играми

Telegram-бот на Python с несколькими играми и статистикой игроков.

## Возможности

- «Угадай число» с уровнями сложности: лёгкий (1–10), средний (1–100) и сложный (1–1000).
- «Камень, ножницы, бумага».
- Подбрасывание монеты и бросок кубика.
- Случайные факты и статистика игр.

## Требования

- Python 3.10 или новее.
- Токен Telegram-бота от [@BotFather](https://t.me/BotFather).

## Установка и запуск

1. Создайте и активируйте виртуальное окружение.
2. Установите зависимости:

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. Создайте файл `.env` рядом с `playground.py` и добавьте токен:

   ```dotenv
   BOT_TOKEN=ваш_токен_бота
   ```

4. Запустите бота:

   ```powershell
   python playground.py
   ```

Статистика хранится локально в `bot_data.json`. Файл `.env`, виртуальное окружение и статистика исключены из Git.

## Команды

- `/start` и `/help` — справка.
- `/guess` — выбрать уровень игры «Угадай число».
- `/guess easy`, `/guess medium`, `/guess hard` — начать игру с выбранной сложностью.
- `/rps` — сыграть в «Камень, ножницы, бумага».
- `/coin` — подбросить монету.
- `/dice` — бросить кубик; например, `/dice 20`.
- `/fact` — получить случайный факт.
- `/stats` — посмотреть статистику.
